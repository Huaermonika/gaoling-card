## 3. 改稿规则

1. **`.fe-*` 前缀不能删**。原工程里每个 `.vue` 自带 scoped 样式，单文件导出没有 scoped，所以用类名前缀代替：`.fe-status` / `.fe-cognition` / `.fe-memory` / `.fe-body` / `.fe-command` / `.fe-system` / `.fe-settings` / `.fe-submodel` / `.fe-extras` / `.fe-app`。删掉前缀，同名选择器会在面板之间互相覆盖（原工程里重复的选择器有 15 处：`.switch`、`.mode-btn`、`.about-row`、`.btn`、`.app-tabs`、`.term-line` 等）。
2. **面板根元素上带着两个类**，例如 `<div class="panel fe-status">`。前缀规则是配合根类写的（`.panel` → `.fe-status.panel`），根类也要一起保留。
3. **`@keyframes` 没加前缀**，动画名沿用原组件里的名字。新增动画请起不重复的名字，重名会互相顶掉。
4. **模板里不能出现裸 `{{ }}` 文本**。预览与真实运行都会走 Vue 编译，花括号会被当成表达式。
5. **`.app-tabs` 的 `grid-template-columns: repeat(3,1fr) 64px repeat(3,1fr)` 是有意的**：三列 + 中央空位 + 三列，给底部主按钮让位。改成 `repeat(6,1fr)` 会让中间两个标签挤在一起。
6. **不要引入 `:deep()`**。单文件版没有 scoped 边界，`:deep()` 在编译后会变成无效选择器；需要穿透就写普通后代选择器。
7. **设置面板出现两次**（958 手机 / 1398 PC）。它们来自同一个 `SettingsPanel.vue`，标题和副标题按位置传了不同文案。只改一处会造成手机和 PC 外观不一致。
8. **`SubmodelSettings` 多包了一层 `<div class="fe-submodel">`**。原组件根节点没有类名，这层包装只为承载作用域前缀，样式已按它写好，别拆。
9. 转成 `v-html` 渲染的聊天正文（`dialogHtml`）不参与样式作用域，同步卡片的样式是独立一套 `.ch-sync-*`。

## 4. 数据层：真的和假的

`<script setup>`（2715–3587）整段是预览替身。真实工程里这些绑定来自 `store.ts`、`ui-state.ts`、`settings.ts` 与各面板自己的脚本。

**按真实逻辑实现、可以放心照着改的：**

- 主题切换、字号、显示形态、画面比例、界面尺寸、长辈模式：`phoneVars` 的算法与 `App.vue` 一致，点是真生效的。
- 电源状态机、身体锁定（含「锁定前状态」记录）、重启动画、系统日志 20 条上限。
- 记忆日志的增删改、时间排序、待填补区。
- 指令覆盖的排序与增删、命令库终端的本地解析。
- 认知四维度、人格三态、认知自洽开关、性格写入。
- 各面板的派生显示（阶段文案、异常计数、命令数、记忆数、Bug 数）。

**用静态快照顶替、只影响预览的：**

| 项目 | 真实做法 |
| --- | --- |
| `store.data` | MVU 变量（结构照 `initvar.yaml`），预览里写死一份 |
| 终端命令库 | 完整命令表在 `CommandPanel.vue` 的 `COMMANDS`，预览只留 help / status / ls / whoami / clear / reboot / power / unlock |
| 发送消息、更新状态 | 预览只写一条系统日志，不碰酒馆接口 |
| 副模型整理记忆 | 预览返回固定的「新增 2 条记忆」 |
| 心跳（电量 / CPU / 内存漂移） | 预览里数值原样返回，不做漂移 |
| 「关闭流式美化」 | 预览强制保持开启：关闭后会切到另一套外壳 `FlatConsole`，不在本次导出范围 |
| 隐藏酒馆原生界面 | 只有开关状态，没有真实 DOM 影响 |

`FlatConsole.vue` / `ConsoleStatusBar.vue` / `ConsoleComposer.vue` **没有导出**。发消息栏与状态栏用的是手机外壳里的 `chat-view` 版本。

## 5. 整合步骤

改完拿回来之后：

1. **按段对照搬回**：模板片段回到 `App.vue` 与各 Panel 的 `<template>`，样式回到各自 `<style lang="scss">`。搬的时候去掉 `.fe-*` 前缀（连同根元素上多出来的那个类），恢复成 scoped 样式即可。
2. **删掉预览专有内容**：`.fe-demo`（15–22）、`.fe-stage`（外层）、预览页样式（5950 之后 `html, body` 与 `.fe-demo` 那几行）、聊天里那张硬编码的 `.ch-sync-card` 演示卡片（60–71、1812–1823）、整段 `<script setup>` 数据层。
3. 构建：

   ```bash
   pnpm build
   node _sync_inline.mjs
   node tavern_sync.mjs bundle 高岭之花
   ```

   `_sync_inline.mjs` 负责把 `dist/高岭之花/脚本/*/index.js` 内联回 `src/高岭之花/index.yaml` 的「内容」字段，漏掉这步打包出来还是旧脚本。产物是 `src/高岭之花/高岭之花.png`。

如果只想改样式、不想动结构，可以直接拿 `<style>` 里对应段替换原组件的 SCSS（去掉前缀、`px` 与嵌套层级按原文件还原），逻辑零改动。

## 6. 覆盖边界与未验证部分

- **只看了渲染结果，没在酒馆里跑过**。原因是预览层把 MVU、酒馆接口、`formatAsDisplayedMessage` 都换成了替身。样式与结构同源，但真实运行时的宏展开、正则替换、事件绑定（`sendControlUpdate` 的差异推送）没有联调。
- **`FlatConsole` 那套外壳没进导出**，关闭流式美化后的界面不在本次改稿范围内。
- **字体差异**：预览用系统字体栈，酒馆里实际字体由主题变量决定，字宽会有细微差别。
- **截图核对过的视图**：手机形态（对话 / 状态 / 认知 / 记忆 / 躯体参数 / 指令 / 系统 / 设置共八屏）、PC 形态（对话 + 终端双栏）。七个页签都量过横向溢出，面板 `scrollWidth == clientWidth`，无横向滚动条；设置页的贴士条 `scrollWidth` 远超容器是刻意的横向跑马灯，外层 `overflow: hidden`。控制台无报错、无 Vue 警告，渲染后的 DOM 里没有残留的 `{{ }}`。
- 预览里的数值都是 2026-04-07 08:40 那一刻的快照，换成别的数值时格子宽度可能变化，尤其是长地点名与长指令内容。
