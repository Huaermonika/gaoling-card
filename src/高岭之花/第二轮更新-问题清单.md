## 二、问题 1 · 流式美化渲染 + 关闭后正文消失

**现象**：
- 个别预设仍然无法正常渲染（接入预设正则后，仍有部分预设渲染不对）。
- 关掉「对白美化」后，正文直接消失。

**研究结论**：

示例的流式正文用酒馆官方 `formatAsDisplayedMessage`，一步做完「替换宏 → 应用正则 → 转 HTML」，挂载用 `host:'div'`（组件落在酒馆页面，能直接调父页面全局函数）。

高岭之花当前是 `host:'iframe'` + 父页面只调 `formatAsTavernRegexedString`（只做「应用正则」一步，返回纯文本），正文 HTML 靠 App.vue 手写 `escapeHtml + renderInline` 拼。

根因：
- `formatAsTavernRegexedString` 不转 HTML。不少预设正则的替换结果本身就是 HTML 片段（加粗 / 着色 / 自定义 span），进了 App.vue 又被 `escapeHtml` 二次转义，显示成字面文本 → 「正则覆盖了、渲染不对」。
- 关闭对白美化正文消失：iframe 挂载与 `.mes_text` 隐藏的交互问题，重构时一起收掉。

重构方向（二选一）：
- A. 改 `host:'div'`，App.vue 直接调 `formatAsDisplayedMessage`（示例原样）。风险：div 模式不能用 tailwind、样式与酒馆互相污染，终端 UI 复杂不划算。
- B. 保持 iframe，父页面 streaming.ts 用 `formatAsDisplayedMessage(raw, { message_id })` 替代 `formatAsTavernRegexedString`，完整 HTML 传给 App.vue 直接 v-html，删掉手写渲染链。改动集中、风险小（倾向）。

**附加修改**：示例「角色卡示例/界面/状态栏」是独立前端界面（`mount('#app')`），扁平卡片结构（WorldSection + DependencyBar + TabNav + 面板）。高岭之花状态栏现在嵌在对话 App.vue 的手机壳里，关对白美化时改成这种扁平卡片。

**涉及文件**：`util/streaming.ts`、`脚本/对话显示/App.vue`、`示例/角色卡示例/`、`示例/流式楼层界面示例/`
