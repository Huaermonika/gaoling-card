## 定位

把「白峰千鹤」这一固定主角替换为可被玩家补全的角色槽位，并在同一套终端 / 认知 / 记忆 / 指令系统上支持多个主要与次要角色。

## 使用规则

1. 本分支的所有改动只写入本目录；`src/高岭之花/` 不动。
2. 需要对照或回滚时，以 `src/高岭之花/` 或 `backups/高岭之花-稳定版-20261103/` 为准。
3. 酒馆中的名称暂用「高岭之花-自定义版」，避免与稳定版互相覆盖；正式发布时改回正式名称。

## 构建与打包

```bash
pnpm build                                        # 产出 dist/高岭之花-自定义版/**
node tavern_sync.mjs bundle "高岭之花-自定义版"        # 产出 高岭之花-自定义版.png
```

## 回滚

- 单文件：从 `backups/高岭之花-稳定版-20261103/` 覆盖回本目录。
- 整卡：删除本目录，重新从稳定版复制。
