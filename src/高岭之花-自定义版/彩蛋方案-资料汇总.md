## 二、技术载体（实现谜题用到的机制）

### 1. 终端命令系统
- 文件：`界面/控制终端/components/CommandPanel.vue`
- `COMMANDS: Record<string, CmdDef>`，其中 `CmdDef = { usage, desc, run: (args) => TermLine[] }`。
- `TermLine = { kind: 'in'|'out'|'err'|'sys', text }`。
- `runTerm()` 用 `COMMANDS[name.toLowerCase()]` 查找执行。
- **隐藏命令** = 存在于 `COMMANDS` 中、但不出现在 `help` 命令的手工枚举 `groups` 数组里 → 玩家试出来才能触发。

### 2. 假文件系统
- `FS_TREE` 是终端里的假文件树，支持 `ls`/`cat`/`rd` 等命令。
- 文件可标 `protected: true`，`rd` 无法删除（用于藏隐藏文件）。
- 现有：`system\logs\system_log.log`（无彩蛋内容）。

### 3. 设置页「关于」
- 文件：`脚本/对话显示/App.vue` 的设置面板。
- 可放置**常驻信息**（用户指定：发布日期 + 具体时间放这里，作为「发布那一刻」信息的来源）。
- 现有独立彩蛋：隐藏主题「樱之回忆」（`unlock sakura` / 密码 `sakura|ying|桜|樱`）——**保留，与本次寻宝彼此独立**。

### 4. 第一条消息
- 文件：`第一条消息/0.txt`，开头是小说式导入 + `<UpdateVariable><initvar>` 状态初始化。
- 已修正一处：第 13 行「最上面一行是四个字」（白峰千鹤 = 4 字）。

## 三、已定稿的方案结构

### 总体：两部分谜题

1. **A 谜题（入口）**：解出「理念 / 诞生 / 花絮 / 致谢」四个板块的**入口**（即怎么进入这几个板块）。
2. **B 谜题（致谢收尾）**：最后的「致谢」板块揭示——前面三个板块（理念、诞生、花絮）**各自藏了一串数字**，三串数字合起来（具体算法待定）就是最终礼物的钥匙。

### 浅层锁 vs 深层数字（核心区分）

- **浅层锁** = 下一扇门的密码，**用过即弃**，谜面里给足提示让玩家能解出。
- **深层数字** = 钥匙碎片，**零提示**，直到「致谢」才点破它的存在与用途。
- 区分信号：**「用过 vs 没用过」**——浅层锁在流程中会被消耗掉，深层数字一直悬而未用，玩家事后回看才意识到。

### 三个板块的数字来源

| 板块 | 数字 | 状态 |
|------|------|------|
| 理念 | 一串数字 | ⏳ 未定来源 |
| 诞生 | セロハンてぇぷ（玻璃纸胶带老师）的 P 站 UID | ✅ 已定：`13360289` |
| 花絮 | 价格串（详见下文） | ✅ 主体已定，算法待定稿 |

### 发布页（第四处藏数字）

- 发布页 = 普通介绍文本 + 功能介绍截图 + 取卡密码等常规信息。
- 藏数字手段（已定方向）：
  1. **反色图片**：一部分功能介绍截图做特殊处理，**反色后能看到一个数字**。
  2. **直白提示图**：另一张功能介绍图里藏更直白的提示。
  3. **文本埋字**：发布页的文字里同时埋信息。
- 目的：让「发布页」也藏一串数字，与三个板块的数字呼应，避免收尾谜题太简单。

### 花絮答案（用户最终纠正后的定论）

> **花絮的答案 = 某个物品的单价（奶茶单价 12 元），不是「花销总额」，也不是「token 用量」。**

### 花絮谜面文案模板（用户定稿，占位符待填）

```
「我做这张角色卡的时候 DeepSeek 涨价了。
  发布那一刻，我看了一眼花销，和当时输入、输出所有的价格。
  整整{花销}元，够我买{杯数}杯奶茶了。
  抹掉小数点——这个数，就是下一扇门。」
```

- 「发布那一刻」的信息来源：设置在「设置 → 关于」里（发布日期 + 具体时间，作为常驻信息）。
- 时间决定 DeepSeek 高峰价 / 低谷价。

### 早期文案（已被上述取代，但含指向深层数字的线索，保留备查）

```
「收尾那几天，它家涨价了。发布那一刻，我看了一眼花销，和当时输入、输出所有的价格。
  整整 97.72 元，够我买几杯奶茶了。抹掉小数点——这个数，就是下一扇门。
  至于它家当时的输入价、输出价，我记在那天的价格表上，你迟早用得到。」
```

> 末句「它家当时的输入价、输出价……你迟早用得到」= 指向深层数字（DeepSeek 输入价 / 输出价），这条线索应保留进最终设计。

### DeepSeek 价格背景（花絮引子）

- 引子：DeepSeek 涨价（角色卡制作期间）。
- 计价：每 100 万 token 计价，**输入价与输出价不同**。
- 优惠时段（低谷价）：北京时间 **00:30–08:30**，半价。
- 深层数字候选：输入价 + 输出价（具体数值待定，与「发布那一刻」的时间相关联确定高峰/低谷）。
