# 游玩流程审查

## 1. 现在的实际流程

```text
打开卡
└ 占位首楼「终端正在初始化……」
   └ 开场首页：自定义 / 白峰千鹤 / 管理
      ├ 自定义：角色 → 开场 → 世界 → 确认 → 写首楼
      ├ 千鹤：档案 → 三条开场 → 开始
      └ 管理：角色库 / 导入导出 / 创意工坊（占位）
         └ 终端
            ├ 状态 / 认知 / 记忆 / 躯体 / 指令 / 系统
            ├ 顶部角色名 → 角色抽屉 → 切换 / 管理
            └ 设置：主题、字号、显示形态、流式、心跳
```

## 2. 断点与缺失

### P0：会卡住玩家

1. **脚本没起来就是死路**
   首楼只有「终端正在初始化……」，没有重试、没有错误提示。现在已经兼容注释被剥掉的情况，但仍缺一个可见的兜底按钮。

2. **开局后回不到角色库**
   开场页只在首楼挂载；开始之后，设置里没有「角色与开场」入口。玩家想改角色、导出、再建一个，只能开新聊天。

3. **第一次进终端没有引导**
   六个页签分别是什么、怎么发消息、怎么切角色、指令怎么用，全靠自己猜。现在只有一条角色切换提示。

4. **没有内容提示**
   卡里有明确的成人向设定（快感值、性单元、机损），首屏没有任何年龄/内容提示。

### P1：能玩，但断

5. **世界只能开局改**
   `世界.设定` 只在创建时填；进游戏后不能改地点、时间、规则，只能等 AI 更新变量。

6. **不能重开或换开场**
   开场写进首楼后没有「重置本聊天」入口；想换只能新聊天。

7. **画廊没有入口**
   图库、头像选择、立绘触发都做好了底层，但玩家点不到。

8. **删除没有撤销**
   记忆删除、合并、角色删除都是即时生效；导入没有覆盖预览。

9. **自定义编辑器看不到终端效果**
   填完不知道角色进终端是什么样，只能开始后才知道。

### P2：体验粗糙

10. 角色库没有搜索、排序、批量导出。
11. 记忆面板不能只看钉选，合并后不能撤销。
12. 桌面端没有键盘快捷键（Enter 发送、Esc 关闭）。
13. 设置项没有说明，不知道「流式美化」「系统心跳」影响什么。

## 3. UX 可以加强的地方

- 首楼兜底：3 秒没弹开场，显示「没有反应？点这里重试」和错误摘要。
- 首次终端三步导览：页签、角色切换、发消息/指令；可跳过，之后在设置里重看。
- 「角色与开场」hub：库、编辑、导出、导入、创意工坊都从这里进。
- 场景卡：当前时间、地点、在场角色，一句话；玩家可直接改。
- 破坏性操作：二次确认 + 撤销 toast（删除记忆、合并、删角色）。
- 导入预览：名字、型号、开场数、是否同名，再决定导入。
- 空态：每个面板给一个下一步动作，不只写「暂无」。
- 自定义预览：右侧或底部放一个终端头部缩略，实时看名字/型号/立绘。
- 记忆：加「只看钉选」「只看重要」，合并可撤销。
- 桌面：Enter 发送、Esc 关闭、数字键切页签。

## 4. AI 生成可以优化的地方

- **提示词预算可见**：档案 2400 字、记忆配额、变量快照各占多少，在设置里显示当前字符数，允许调。
- **变量更新失败要有反馈**：AI 输出坏 JSON 时，现在多半静默失败；应提示哪一轮、哪个字段，并提供重试。
- **场景锚点**：每轮注入「时间 / 地点 / 在场角色」一行，防止 AI 把场景写漂。
- **记忆去重**：同一天、同一件事反复写入时合并；长线记忆做摘要，不要无限堆。
- **多角色说话人**：当前角色完整档案，其他角色只给摘要；生成时明确谁在说话，避免张冠李戴。
- **指令解释**：玩家写「锁住她的右手」时，注入当前躯体部位与锁定状态，减少 AI 猜错部位。
- **开场衔接**：首楼写入后，下一轮提示词要带「开场刚发生的事」，避免 AI 当没发生过。
- **成本可见**：副模型整理记忆、变量更新的调用次数与 token，在设置里给个粗略统计。
- **图片**：画廊接好后，触发立绘时把「当前立绘」写进提示词，让 AI 知道玩家看到了什么。

## 5. 建议顺序

1. 首楼兜底 + 错误提示；
2. 设置里的「角色与开场」hub；
3. 首次终端导览；
4. 内容提示；
5. 场景卡与游戏内世界编辑；
6. 画廊入口；
7. 删除撤销、导入预览；
8. 提示词预算与变量更新失败提示。
