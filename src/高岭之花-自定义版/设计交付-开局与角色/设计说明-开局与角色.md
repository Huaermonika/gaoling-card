# 开局与角色 · 设计 v4

> 以 A（定格）为基础。首页 = 翻页器：**1 自定义 / 2 千鹤 / 3 管理**。
> 每页一句话简介 + 一个开始按钮；开场白不在首页选，进千鹤子页选。
> 尾页恒为管理；未来新增角色在中间插页，页签横向滚动扩展。

## 0. 约定

- 自动保存：输入后 800ms 防抖写 IndexedDB；离开/切页 flush。
- 草稿 = 记录 `status:'draft'`，从未「开始」。
- 「开始」= 写首楼 + `stat_data` + 置 `ch_opening_done`（复用 `apply.ts`），记录置 `ready`；开始后仍可编辑/导出，当前聊天已固定。
- 官方只读；「复制为自定义」生成副本（`source:'official-copy'`）。
- 库：IndexedDB 角色库 + JSON 导入导出。导出 kinds：`gaoling.character` / `gaoling.collection`（批量）/ `gaoling.opening`（只导开场）。
- 新增字段：`status`、`pinnedAt`。新增 token：`--font-serif`（展示衬线）。颜色零新增。
- 校验：姓名 1–20 字必填；开场非空；「开始」前一次列出缺项，不阻断填写。
- 导入：逐字段报错；同名生成「名字 · 2」；图片超 512 压缩；collection 先预览再入库。
- 删除：二次确认，含角色名与「不影响当前聊天」。
- 根节点无 `position:fixed`；覆盖层 `absolute; inset:0`，父级 `.phone` relative。

## 1. 首页 · 翻页器

```
1 自定义 ── 2 千鹤 ── 3 管理（尾页恒为管理）
```

- 每页同构：图 + 标题 + mono 一行 + 一句简介 + 一个开始按钮。
- 页签：‹ 自定义 · 千鹤 · 管理 ›；左右滑动或点页签翻页。
- 页 1 自定义：占位图（＋ 圆环，待用户出图替换）；标题「你的角色」；简介「名字、开场都由你定。」。
- 页 2 千鹤：千鹤卡图；标题「白峰千鹤」；简介「仿生机器人。持有者是你，完整控制权限。」。
- 页 3 管理：面板三行（导入 / 导出 / 设置）；标题「管理」；按钮「进入管理」。
- 桌面：三栏并排全见（940×600），新增角色往中间插列。

## 2. 子页（点开始进入）

- **千鹤 · 详细信息**：档案（型号 / 学园 / 权限）+ 三条开场白三选一（教室·初次连接 / 放学后·单独辅导 / 周末·家中）+ 选中出首句 + 「从这个开场开始」。
  - 开场白 = 原本的第一条信息；三条副题：早自习，终端第一次亮起 / 教室里只剩你们两个人 / 她已经把你当作恋人。
- **自定义流程**：占位图 + 名字输入 + 开场编辑 + 「开始」。
- **管理**：导入（从 JSON 文件）/ 导出（当前预设）/ 设置（默认页 · 自动保存 · 开场预览等）。

## 3. 五屏

| 屏 | 结构 |
| --- | --- |
| 1 首次打开 | 翻页器三页，每页简介+开始 |
| 2 千鹤 · 详细信息 | 档案 + 三条开场白选择 + 开始 |
| 3 自定义流程 | 占位图 / 名字 / 开场 + 开始 |
| 4 管理 | 导入导出 + 设置 |

## 4. 组件

`FlipPages`（可扩展页签 + 插页）/ `OfficialDetail`（开场白选择）/ `CustomFlow` / `ManagerPage` / `LibraryDrawer`。
复用：`presets.ts` `apply.ts` `db.ts` `role-art.ts`；`--font-serif` 仅展示性标题与名字。
