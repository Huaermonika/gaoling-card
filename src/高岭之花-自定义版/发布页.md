基于セロハンてぇぷ（玻璃纸胶带老师）「校园 × 机娘 × 遥控器」题材的角色卡。

私立清岭学园的高岭之花，白峰千鹤。全校都知道她，没人能靠近她。

只有你知道真相：她是一台仿生机器人，型号 AN-0170A。而她的控制终端，就装在你的手机里。意识、认知、身体、电量、快感值，几十项数据实时刷新。

你是她名下的 user。隔着屏幕看，还是亲手操作，随你。

## 你可以是——

· user：通过手机终端实时查看她的意识、电量、好感、身体状态，看她的一举一动都落在数据里
· 操控者：冻结她的意识、停止她的人格、锁定她的身体，让这台冰冷的机体按你的指令动作
· 她的「现实」：改写她的身份认知，让她继续当一个毫无自觉的人类女学生，或是让她醒过来、知道自己是一台机器
· 恋人 / 主人：把她的身份覆盖成恋人、宠物、玩物，她会毫不怀疑地接受
· 试探她底线的人：调整敏感度、力量限制器，一步步看这朵高岭之花露出破绽

## 核心系统

**三层状态机**
电源（开机 / 待机 / 关机）、意识（运行中 / 冻结 / 停止）、系统（正常 / 未响应 / 休眠 / 关闭）三套状态各自独立记录，不互相反推。冻结就是冻结，她停在那里，不眨眼、不说话、不记东西；停止只剩「是」「执行完成」；关机后电量不再掉，全部数据冻结。

**认知四维度 + 认知自洽**
身份、身体、处境、常识四个维度独立，可单独覆盖。你可以只改「她认为自己是谁」，也可以把她的「常识」整个换掉。认知自洽开启时，系统自动抹平一切违和；关闭后，她可能突然察觉自己不需要呼吸。

**控制终端 APP**
手机里的命令系统、假文件系统、设置页，加上实时状态栏。电量随剧情消耗，CPU / 内存随她的活动起伏，好感度、快感值、敏感度、7 个部位的机体损伤、身体锁定、指令覆盖，全部量化显示。

**身体结构**
电子脑、总线、散热、电量核心、生殖模块；头、胸、腹三处维护舱门，打开是维护接口和内部结构。

**解密彩蛋**
手记四卷（理念 / 诞生 / 花絮 / 致谢）散落在终端和设置页里，另有隐藏主题「樱之回忆」。不写在明面上，留给愿意深挖的人。
